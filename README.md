
# COVID-19 Data Visualization and Storytelling

## Project Overview

This project analyzes COVID-19 data using Python and presents the findings through advanced data visualizations and data storytelling.

The analysis focuses on identifying trends, geographic differences, relationships, distributions, and important patterns in COVID-19 data.

## Dataset

The dataset contains COVID-19 observations across 187 countries and regions.

### Dataset Period

22 January 2020 to 27 July 2020

### Dataset Size

- 49,068 records
- 10 columns
- 187 countries/regions

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

## Visualizations

The project includes:

1. Global Confirmed COVID-19 Cases Over Time
2. Top 10 Countries by Confirmed Cases
3. Global COVID-19 Deaths Over Time
4. Confirmed Cases vs Deaths
5. COVID-19 Correlation Heatmap
6. Distribution and Outlier Analysis

## Key Analysis Areas

- Time-series trends
- Country-level comparison
- Mortality trends
- Relationship between confirmed cases and deaths
- Correlation analysis
- Distribution and outlier detection

## Project Files

- `COVID_19_Advanced_Data_Visualization.ipynb` — Complete Python analysis
- `COVID_19_Advanced_Data_Visualization_Report.docx` — Detailed project report
- `visualizations/` — Generated charts
- `dataset/` — Dataset, if included

## Conclusion

The project demonstrates how Python-based data visualization can transform a large COVID-19 dataset into an understandable visual narrative for non-technical audiences.
